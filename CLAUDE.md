# Project Crawlers

**The games being worked on are Crawlers v2 and Crawlers v3, not this repository.** Ask which one if it is not clear.

- Crawlers v3 (working title, an arcade idle dungeon crawler forked from v2's look) is https://github.com/myrmecbruh/Crawlers-v3
  (in a session it is cloned at `/home/user/crawlers-v3`). Its own `CLAUDE.md`, `AGENTS.md` and `docs/` are its instructions.
  It plays at https://myrmecbruh.github.io/Project-Crawlers/v3/ (its `publish.py` puts it in the `v3/` folder of `gh-pages`).
- Crawlers v2 is https://github.com/myrmecbruh/Crawlers_v2 (in a session it is cloned at `/home/user/crawlers_v2`).
- Its own `CLAUDE.md`, `AGENTS.md` and `docs/` (RULEBOOK, DECISIONS, ROADMAP) are the instructions. Read them before anything else.
- The permanent playable link is still https://myrmecbruh.github.io/Project-Crawlers/ : v2's `publish.py` puts the game there,
  on this repository's `gh-pages` branch.

This repository holds the first game (v0.x, a 2D canvas game), kept for reference only. Its old instructions are in
`docs/FIRST-GAME-NOTES.md`. Nothing in them describes v2: its files, renderer, tests, scale and commands are all different,
so do not follow them for v2 work.
